# Clawback brand assets

Every file in this folder is generated by [`scripts/render_brand.py`](../../scripts/render_brand.py). Do not
edit the images by hand: change the script and run it again.

```bash
pip install playwright pillow
python scripts/render_brand.py      # uses the installed Microsoft Edge; or set CLAWBACK_BROWSER=chromium
                                    # after `python -m playwright install chromium`
```

## The mark

A pixel-art envelope on a strict 16 x 16 grid, hooked by three claws that pull it back. The grid is written
out character by character in `GRID` at the top of the script. It is a plain, generic envelope (outline and a V
flap); it does not imitate any email provider's logo.

- SVGs draw one `<rect>` per run of same-coloured pixels with `shape-rendering="crispEdges"`.
- PNGs are drawn pixel by pixel and enlarged by whole numbers with nearest-neighbour scaling, so every PNG
  holds exactly four colours (tile, outline, paper, transparent) and no blurred edges.
- Show it at a multiple of 16 px (16, 32, 48, 64 ...) to keep every pixel square.
- The teal tile carries its own background, so one version works on light and dark backgrounds; no separate
  dark variant is needed.

Colours: tile `#2dd4bf`, outline `#0b1f2a`, paper `#ffffff` (the same tokens the web app uses).

Like the web app's two themes, every banner, strip, GIF and preview is pure black (`#000000`, text
`#f2f2f2`) or pure white (`#ffffff`, text `#0a0a0a`), with the teal mark as the only colour.

## Files

| File | Size | Used for |
|---|---|---|
| `logo.svg` | vector, 16 x 16 grid | Source-quality logo |
| `logo-16.png` ... `logo-512.png` | 16, 32, 64, 128, 256, 512 px | Avatars, docs, slides |
| `banner-dark.png`, `banner-light.png` (+ `.svg`) | 1600 x 480 | README header (`<picture>`, follows the viewer's GitHub theme) |
| `social-preview.png` | 1280 x 640, < 1 MB | Repository social preview (Settings > General > Social preview) |
| `feature-strip-dark.png`, `feature-strip-light.png` | 1600 x 1172 | README "how it works" strip |
| `flow.gif` | 960 x 640, 4 frames, 2 s each | Short loop of the same four steps, for posts and release notes |
| `app/` | see [app/README.md](app/README.md) | Ready-made favicon and in-app logo files for the web app |

The banner and social preview keep their text inside generous margins (social preview: x 72-664, y 72-568
of 1280 x 640) so nothing important is lost when a site crops the card.

are invented demo data. No third-party logos or trademarks are used. Nothing is downloaded while rendering.

The SVG banners name `Inter` first and fall back to system fonts, so a viewer without Inter installed sees a
slightly different typeface in the `.svg`; the `.png` files are the reference rendering.
