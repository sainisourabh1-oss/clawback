# Web app icon files (ready to copy)

Generated by `scripts/render_brand.py` from the same 16 x 16 pixel grid as the brand logo. They are kept
here, outside the package, so the package can be updated in one deliberate change.

| File here | Replace / add in the package | Notes |
|---|---|---|
| `favicon.svg` | `clawback/web/static/favicon.svg` (replace) | Same name, already linked from `index.html` and served by `server.py`. |
| `logo.svg` | `clawback/web/static/logo.svg` (replace) | Header logo. `index.html` shows it at 36 x 36; 32 or 48 keeps the pixels square (36 is 2.25x and makes uneven pixel widths). |
| `card_logo_group.svg` | body of `logo_group()` in `clawback/card.py` | The `<g transform="scale(4)">...</g>` element drops into the shareable card's 64-unit slot unchanged. |
| `favicon.ico` (16, 32, 48) | optional: `clawback/web/static/favicon.ico` | Needs `"favicon.ico": "image/x-icon"` in the static whitelist in `clawback/web/server.py`; `pyproject.toml` already packages `web/static/*.ico`. Modern browsers use the SVG. |
| `favicon-16.png`, `favicon-32.png`, `favicon-48.png`, `favicon-192.png` | optional | PNG fallbacks; 192 px for a web app manifest if one is ever added. |

After replacing them, regenerate the screenshots (`python scripts/ui_smoke.py . docs/screenshots`) and then
the brand images (`python scripts/render_brand.py`), because the README screenshots, the feature strip, the
GIF and the social preview all show the app's header logo.
